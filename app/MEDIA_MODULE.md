# Медиа Модуль для Infinity AI Search System

## Возможности

### 🎵 Музыка
- **Индексация**: Сканирование директорий с музыкой и извлечение метаданных
- **Воспроизведение**: Мощный аудио плеер с поддержкой:
  - Play/Pause/Next/Previous
  - Прогресс-бар с перемоткой
  - Регулятор громкости
  - Автоматическое переключение на следующий трек
- **Группировка**: 
  - Все треки
  - По исполнителям
  - По альбомам
  - По жанрам
- **Поиск**: Быстрый поиск по названию, исполнителю, альбому
- **Избранное**: Добавление треков в избранное
- **Плейлисты**: Создание и управление плейлистами
- **Страница трека**: 
  - Отображение информации о треке
  - Текст песни (парсинг из интернета или локальное хранение)
  - Информация об исполнителе
  - Изображения исполнителя (до 5)
  - Все треки исполнителя
  - Альбомы исполнителя

### 🎬 Видео
- **Индексация**: Сканирование директорий с видео
- **Страница фильма**:
  - Обложка фильма
  - Информация о фильме
  - Актеры (с возможностью просмотра других фильмов с их участием)
  - Все данные кешируются в JSON файлах

### 📁 Файловый менеджер
- Управление медиа файлами
- Просмотр структуры директорий

### 📃 Плейлисты
- Создание новых плейлистов
- Добавление/удаление треков
- Управление плейлистами

### ❤️ Избранное
- Избранные треки
- Избранные видео

## Установка

### Обязательные зависимости

Для чтения метаданных аудио файлов (рекомендуется):

```bash
pip3 install mutagen
```

ИЛИ (альтернатива):

```bash
pip3 install tinytag
```

### Структура данных

Все данные медиа хранятся в `~/.infinity/media/`:

```
~/.infinity/media/
├── music_index.json       # Индекс музыки
├── video_index.json       # Индекс видео
├── favorites.json         # Избранное
├── lyrics/                # Тексты песен
│   └── {track_id}.json
├── artists/               # Информация об исполнителях
│   └── {artist_name}.json
└── playlists/             # Плейлисты
    └── {playlist_id}.json
```

## Использование

### 1. Настройка директорий

1. Откройте модуль "Медиа" на главной странице
2. Перейдите в раздел "Настройки"
3. Укажите директории с музыкой и видео через запятую
4. Нажмите "Индексировать музыку" или "Индексировать видео"

### 2. Воспроизведение музыки

- Кликните на трек для воспроизведения
- Используйте элементы управления в плеере внизу страницы
- Наведите на трек для появления дополнительных действий:
  - ❤️ Добавить в избранное
  - 📄 Открыть страницу трека
  - ➕ Добавить в плейлист

### 3. Группировка

Используйте вкладки для переключения между видами:
- **Все треки** - полный список
- **По исполнителям** - группировка по артистам
- **По альбомам** - группировка по альбомам
- **По жанрам** - группировка по жанрам

### 4. Поиск

Введите запрос в строку поиска для быстрого нахождения треков.

## API Endpoints

### GET
- `/api/media/music-index` - Получить индекс музыки
- `/api/media/video-index` - Получить индекс видео
- `/api/media/search?q=query` - Поиск треков
- `/api/media/tracks-by-artist?artist=name` - Треки исполнителя
- `/api/media/tracks-by-album?album=name` - Треки альбома
- `/api/media/lyrics?track_id=id` - Текст песни
- `/api/media/artist-info?artist=name` - Информация об исполнителе
- `/api/media/favorites` - Избранное
- `/api/media/playlists` - Плейлисты
- `/api/media/playlist?id=id` - Конкретный плейлист
- `/api/media/stream/{base64_path}` - Потоковое аудио

### POST
- `/api/media/rebuild-music` - Переиндексировать музыку
- `/api/media/rebuild-video` - Переиндексировать видео
- `/api/media/favorites/add` - Добавить в избранное
- `/api/media/favorites/remove` - Удалить из избранного
- `/api/media/playlist/create` - Создать плейлист
- `/api/media/playlist/update` - Обновить плейлист
- `/api/media/playlist/add-track` - Добавить трек в плейлист
- `/api/media/playlist/remove-track` - Удалить трек из плейлиста
- `/api/media/playlist/delete` - Удалить плейлист
- `/api/media/lyrics/save` - Сохранить текст песни
- `/api/media/lyrics/fetch` - Загрузить текст из интернета
- `/api/media/artist-info/save` - Сохранить информацию об исполнителе

## Troubleshooting

### Музыка не индексируется
- Проверьте что директории указаны правильно
- Убедитесь что файлы имеют правильные расширения
- Проверьте логи сервера на ошибки

### Нет метаданных
- Установите `mutagen`: `pip3 install mutagen`
- Файлы могут не содержать ID3 теги
- Информация будет извлечена из имен файлов и структуры папок

### Плеер не воспроизводит
- Проверьте что браузер поддерживает HTML5 Audio
- Убедитесь что файлы доступны по указанному пути
- Проверьте права доступа к файлам

## Интеграция с текстами песен

Модуль поддерживает загрузку текстов песен из:
1. Локального кеша (`~/.infinity/media/lyrics/`)
2. API Lyrics.ovh (автоматически при отсутствии локального текста)

Тексты сохраняются в JSON формате с поддержкой:
- Обычного текста
- Синхронизированного текста (LRC формат)
- Источника текста

## Интеграция с информацией об исполнителях

Информация об исполнителях хранится в:
- `~/.infinity/media/artists/{artist_name}.json`

Включает:
- Биография
- Изображения (до 5)
- Жанры
- Альбомы
- Количество треков
- Общая длительность

## Примечания

- **LLM-описания фильмов отключены по умолчанию.** Настройка `media_llm_descriptions` (галочка «Генерировать описания фильмов через ИИ (LLM)» в разделе «Видео» настроек медиа). Когда выключено, описания берутся только из TMDB/Wikipedia/ZIM и локальная LLM не вызывается. Включите, если нужны AI-описания для видео, не найденных в онлайн/офлайн источниках.
- При первом запуске индексиция может занять время в зависимости от количества файлов
- Рекомендовано переиндексировать при добавлении новых файлов
- Все данные хранятся локально
- Поддержка.light и .dark тем
