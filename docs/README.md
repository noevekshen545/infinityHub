## С чего начать

1. Если нужен готовый вариант — скачайте портативный архив из **Releases** и запустите
   `start.bat`.
2. Если хотите собрать из исходников — прочитайте [INSTALL.md](INSTALL.md), раздел
   «Из исходников».
3. После первого запуска откройте [USER-GUIDE.md](USER-GUIDE.md) — там описано, где
   что находится.
4. Если что-то не работает — начните с [FAQ.md](FAQ.md).

## Коротко о проекте

Infinity Search — локальная среда для работы с информацией: поиск, заметки, книги,
медиа, новости, файлы, обучение, общение и встроенные приложения. Данные хранятся на
вашем диске, интернет нужен только для внешних источников и сервисов, которые вы
подключите сами.
