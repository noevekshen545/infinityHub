# Тесты ботов социальной сети

Сквозные тесты модуля ботов и Telegram-совместимого Bot API. Каждый тест
поднимает приложение на `TestClient` и работает с настоящими HTTP-запросами
и настоящей БД — но во временном каталоге, чтобы не трогать рабочую.

## Запуск

```cmd
set PYTHONIOENCODING=utf-8
python _t_bot1.py
```

`PYTHONIOENCODING` обязателен: иначе Windows-консоль (cp1251) падает на
кириллице в `print`. Запускать по одному файлу — тесты занимают по 15–25 секунд.

## Файлы

| Файл | Что проверяет | Соответствует шагу плана |
|---|---|---|
| `_t_bot1.py` | схема БД, генерация и проверка токенов, хранение хэша, перевыпуск | шаг 1 |
| `_t_bot2.py` | `getMe`, `deleteWebhook`, `getWebhookInfo`, ошибки 401/404, аудит | шаг 2 |
| `_t_bot3.py` | постановка в очередь, отбор ботов, TTL, смещение `offset` | шаг 3 |
| `_t_bot4.py` | `getUpdates` end-to-end: сообщение в чате → очередь → выдача боту | шаг 4 |
| `_t_bot5.py` | `sendMessage` полным циклом, проверки отказов | шаг 5 |
| `_t_bot6.py` | webhook: доставка на живой HTTP-сервер, HMAC, SSRF-защита | шаг 6 |
| `_t_bot7.py` | разбор команд и упоминаний в `entities` | шаг 7 |
| `_t_bot8.py` | методы уровня 2: `sendChatAction`, `editMessageText`, `deleteMessage`, команды, чат | шаг 8 |
| `_t_bot9.py` | BotFather: создание бота, выдача и перевыпуск токена, страница | шаг 9 |
| `_t_js.py` | синтаксис JS шаблона через `node --check`; страница передаётся аргументом | шаги 9–10 |
| `_t_attachments.py` | публикация с вложением без текста и отклонение пустых постов | задачи 1.1, 1.7 |
| `_t_group_albums.py` | **41 проверка**: альбомы групп — CRUD, типы, приватность, права | задача 1.5 |
| `_t_articles.py` | **39 проверок**: статьи — секции, статусы, права, обложка, просмотры | задача 1.6 |
| `_t_server_channels.py` | **45 проверок**: альбомы и статьи каналов сервера, приватность канала, разграничение с группами | задача 1.7 |
| `_t_bot_security.py` | **28 проверок безопасности**, печатает `FAIL_COUNT=N` | шаг 11 |

Все тесты печатают в конце `cleanup done` и сами удаляют свои данные.
Признак успеха: нет слова `Traceback` в выводе, для сводного теста —
`FAIL_COUNT=0`.

## Важно

Одноразовые скрипты правок шаблонов удалены: они свою задачу выполнили, а
оставить их значило бы оставить в репозитории код, который нельзя применять
повторно без вреда. Правки в файлах шаблонов делались через Python, потому
что редактор читает их в другой кодировке и не находит строки по тексту —
если придётся править `page_social_*.html` снова, используйте тот же приём.
