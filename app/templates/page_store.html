Создание репозитория

Репозиторий — это JSON-каталог с торрентами. Загрузите его файлом с ПК, вставьте URL/путь до JSON или добавьте встроенный каталог. Каждый элемент должен иметь title и один из источников: magnet или torrent_url. 

{
  "name": "Мой каталог",
  "description": "Описание каталога",
  "items": [
    {
      "title": "Фильм (BluRay)",
      "type": "video",
      "size": "1.4 ГБ",
      "year": 2025,
      "magnet": "magnet:?xt=urn:btih:<хэш>&dn=..."
    },
    {
      "title": "Концерт (FLAC)",
      "type": "music",
      "torrent_url": "https://archive.org/download/ID/ID_archive.torrent"
    }
  ]
}
  • type — music, video, software, games, books, photos, documents, archives или other (по умолчанию video)
  • title — обязателен; description, size, year — опционально
  • Вместо magnet можно дать torrent_url на .torrent файл по HTTP
