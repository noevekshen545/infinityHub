Шифрование медиа (опция)

При включении файл на диске заменяется контейнером .infenc: из проводника Windows его не открыть. Воспроизведение внутри приложения работает как раньше (расшифровка на лету). Ключ локальный — на другой машине файлы не восстановить. По умолчанию выключено.

Загрузка в медиатеку (опция)

Принимает файл, ZIP или целую папку с телефона или другого компьютера: байты идут чанками, готовое ложится в ваш каталог библиотеки и индексируется. Имена из архива очищаются от пути и от «..», в ход идут только форматы этой категории, перезапись существующего исключена.
По умолчанию выключено.

Чистка битого (опция)

Находит треки, фильмы и фото, которых нет на диске, файлы нулевого размера и контейнеры, которые не читаются, и убирает их строки из индекса; связи (избранное, плейлисты, история, альбомы и теги фото) дочищаются следом. Сами файлы остаются на диске. Чтобы автосинхронизация не добавила их обратно, чистка запоминает отпечаток файла (путь, размер, время изменения) и такие файлы пропускает; изменённый файл индексируется заново, а вернуть всё можно кнопкой «Вернуть в индекс». Каталог, недоступный в этот момент (отключённый диск, пропавшая шара), не трогается вовсе, а если нечитаемых слишком много, категория останавливается с объяснением в отчёте. Область — только то, что видно твоему профилю. По умолчанию выключено.

mutagen для музыки, ffprobe для видео, PIL для фото. Находит «файл есть, но не играется», на большой библиотеке идёт минуты: без галочки проверяются только отсутствие файла и нулевой размер.

Движок воспроизведения

FFmpeg — транскодирование неподдерживаемых форматов через ffmpeg (работает всегда).
VLC — стриминг через HLS; если в сборке VLC нет HLS-муксера (типично для Linux), поток всё равно создаёт FFmpeg.

Поиск по библиотеке

Слова сравниваются по отдельности: «боксер майбай» находит «Майбай — Боксёр», «metallica» и «металлика» — один и тот же исполнитель, пропущенная или переставленная буква не теряет трек. Выдача упорядочена по близости к запросу, а не по порядку индекса. Enter в строке поиска повторяет запрос, даже если текст не менялся.

Рекомендации фильмов и сериалов

Подбор идёт по тому, что ты уже смотрел и что отметил сердечком: тот же сериал, режиссёр, актёры и жанр. У сборников-«компиляций» альбом не считается сигналом — иначе библиотека превращается в чужие ротации. Страница может быть короче двадцати: нечего добираем случайным, а отдаём меньше и своих. Рекомендации музыки считаются всегда, этот рубильник ни на них, ни на данные не влияет — выключением ничего не удаляется.

Создание репозитория

Репозиторий — это JSON-каталог с торрентами. Загрузите его файлом с ПК, вставьте URL/путь до JSON или добавьте встроенный каталог. Каждый элемент должен иметь title и один из источников: magnet или torrent_url. 

{
  "name": "Мой каталог",
  "description": "Описание каталога",
  "items": [
    {
      "title": "Фильм (BluRay)",
      "type": "video",
      "size": "1.4 ГБ",
      "year": 2025,
      "magnet": "magnet:?xt=urn:btih:<хэш>&dn=..."
    },
    {
      "title": "Концерт (FLAC)",
      "type": "music",
      "torrent_url": "https://archive.org/download/ID/ID_archive.torrent"
    }
  ]
}
  • type — music, video, software, games, books, photos, documents, archives или other (по умолчанию video)
  • title — обязателен; description, size, year — опционально
  • Вместо magnet можно дать torrent_url на .torrent файл по HTTP
