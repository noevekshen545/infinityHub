## Where to start

1. Want a ready-to-run build? Download the portable archive from **Releases** and run
   `start.bat`.
2. Want to build from source? Read [INSTALL.md](INSTALL.md).
3. After the first launch, open [USER-GUIDE.md](USER-GUIDE.md).
4. If something does not work, start with [FAQ.md](FAQ.md).

## Short overview

Infinity Search is a local-first workspace for information: search, notes, books,
media, news, files, learning, communication and built-in apps. Data stays on your
disk; the internet is only needed for external sources and services you connect
yourself.

Russian documentation lives in [`docs/README.md`](../README.md).
