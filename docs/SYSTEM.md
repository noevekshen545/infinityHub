## 1. Кратко о системе

Infinity Search — локальная среда для работы с информацией. Она запускает
веб-сервер на вашем компьютере, открывает интерфейс в окне приложения и хранит все
данные на диске. Внутри — независимые модули, которые делят один поисковый индекс,
один набор профилей и один локальный движок моделей.

Один вход — и доступны:

- поиск по файлам, заметкам, книгам, новостям и офлайн-библиотекам;
- заметки с графом связей и несколькими редакторами;
- библиотека книг и читалка;
- офлайн-энциклопедии ZIM;
- музыка, видео и фото;
- новости, погода, курсы, календарь и дашборд;
- файловый менеджер с корзиной, шифрованием и общим доступом;
- локальная соцсеть с федерацией;
- курсы и карточки для обучения;
- каталог приложений и магазин расширений;
- помощник на локальных моделях;
- голосовой ввод, озвучивание и 3D-аватар;
- автоматизация, горячие клавиши и скриншоты;
- профили, админ-панель, резервные копии и восстановление.

Интернет нужен только для новостей, погоды, внешних API и федерации — и только
если вы сами это включите.

## 2. Принципы

### 2.1. Локальность

Данные, индексы, модели и настройки лежат на диске. Сервер по умолчанию слушает
`127.0.0.1` и доступен только с этого компьютера. Доступ по локальной сети —
отдельный рубильник в админ-панели.

### 2.2. Модульность

Каждый раздел — отдельный модуль со своими маршрутами, хранилищем и настройками.
Модуль можно отключить, не удаляя данные. Новые возможности добавляются
расширениями и приложениями, а не правкой ядра.

### 2.3. Профили

Один компьютер — несколько независимых пространств. У каждого профиля свои
заметки, книги, настройки, доступы и история. Профили не видят данные друг друга,
если это не разрешено явно.

### 2.4. Офлайн-first

Интерфейс, поиск, книги, заметки, медиа и офлайн-энциклопедии работают без
интернета. Сетевые функции — новости, погода, федерация, внешние модели — включаются
отдельно.

### 2.5. Восстановление

Система умеет запускаться в безопасном режиме, откатывать расширения, делать
резервные копии и перезапускать сервер после сбоя. Ошибка одного модуля не должна
уносить всё приложение.

## 3. Архитектура

```
┌──────────────────────────────────────────────────────────────┐
│  Браузер / Electron                                           │
│  HTML + CSS + JavaScript, окна, панель задач, темы            │
└───────────────────────────┬──────────────────────────────────┘
                            │ HTTP + WebSocket
┌───────────────────────────▼──────────────────────────────────┐
│  app/main.py — FastAPI + uvicorn, один процесс                │
│                                                              │
│  app/routes/      71 файл маршрутов                          │
│  app/modules/     47 модулей предметной области               │
│  app/server/      сборка приложения, конфиг, безопасность     │
│  app/legacy/      исторические секции                         │
│  app/templates/   89 HTML-страниц                             │
│  app/static/      CSS, JS, библиотеки                         │
└───────┬───────────────────────┬──────────────────────────────┘
        │                       │
        ▼                       ▼
┌───────────────┐       ┌──────────────────────────────────────┐
│  Хранилище    │       │  Внешние движки                      │
│  JSON, SQLite │       │  engine/  — llama.cpp                 │
│  Tantivy      │       │  models/  — gguf, whisper, silero…    │
│  Qdrant       │       │  hermes/  — Hermes Agent              │
│  файлы        │       │  ms-playwright/ — браузер             │
└───────────────┘       └──────────────────────────────────────┘
```

### 3.1. Слои

| Слой | Что делает |
|---|---|
| Интерфейс | HTML-шаблоны, CSS, JavaScript, окна, темы |
| Маршруты | HTTP-API, страницы, WebSocket |
| Модули | бизнес-логика: книги, медиа, заметки, соцсеть |
| Хранилище | JSON, SQLite, индексы, файлы, кэш |
| Движки | llama.cpp, Whisper, Silero, Piper, Playwright |
| Оболочка | Electron: окно, трей, горячие клавиши |

### 3.2. Один процесс

Сервер работает одним процессом `app/main.py`. Тяжёлые операции выносятся в пулы
потоков и фоновые задачи. Расширения с sandbox запускаются отдельными процессами.

## 4. Запуск и жизненный цикл

### 4.1. Портативная версия

`start.bat`:

1. выставляет переменные окружения: `INFINITY_ROOT`, `INFINITY_DATA_DIR`,
   `INFINITY_ENGINE_DIR`, `INFINITY_MODELS_DIR`;
2. создаёт рабочие каталоги;
3. запускает `InfinitySearch.exe`;
4. сервер открывает `http://127.0.0.1:8281`.

`start-desktop.bat` дополнительно запускает Electron-оболочку.

### 4.2. Из исходников

`run-dev.bat` использует `.venv` или портативный Python и запускает
`app/main.py --server --port 8281`.

### 4.3. Recovery guard

Если запускать `main.py` без `--server`, стартует сторож восстановления:

- проверяет предыдущий запуск;
- считает падения;
- при необходимости включает безопасный режим;
- может перезапустить сервер;
- ведёт журнал восстановления.

Флаги:

| Флаг | Что делает |
|---|---|
| `--server` | запустить сервер напрямую, без сторожа |
| `--no-recovery` | без сторожа и восстановления |
| `--safe-mode` | не загружать расширения |
| `--restore` | восстановить критические файлы |
| `--port` | порт |
| `--host` | адрес |

### 4.4. Прогрев

После старта сервер прогревает частые маршруты: книги, медиа, новости, заметки,
расширения. Это снижает задержку первого открытия разделов.

### 4.5. Первый запуск

Создаются:

```
data/
├─ profiles/
│  ├─ default/
│  └─ ...
├─ index/
├─ notes/
├─ zim/
├─ html/
└─ home/
logs/
models/
engine/
```

Профиль по умолчанию создаётся автоматически. Если включён онбординг, интерфейс
предложит выбрать тему, папки и основные параметры.

## 5. Интерфейс и рабочий стол

### 5.1. Главный экран

Плитки разделов, строка поиска, быстрые действия и сводка дня. Плитки можно
скрывать, менять порядок и группировать.

### 5.2. Рабочий стол

`/desktop` — оконный менеджер:

- окна модулей открываются поверх рабочего стола;
- окна можно перетаскивать, сворачивать и прикреплять к краям;
- поддерживается тайлинг и сетка;
- несколько рабочих столов;
- свои обои и панель задач;
- контекстное меню и иконки.

### 5.3. Панель задач

Снизу — быстрый доступ к поиску, заметкам, музыке, уведомлениям, календарю,
рабочим столам и настройкам. Панель можно сделать прозрачной.

### 5.4. Темы

- светлая и тёмная;
- акцентный цвет для кнопок и ссылок;
- свои шрифты и размер текста;
- компактный и просторный режимы;
- темы для отдельных страниц.

### 5.5. Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+K` | поиск |
| `Shift+Space` | быстрая заметка |
| `Ctrl+,` | настройки |
| `Ctrl+Shift+T` | восстановить закрытое окно |
| `Alt+Tab` | переключение окон |
| `F11` | полный экран |
| `Ctrl+Shift+S` | сохранить (в редакторах) |

Полный список — в настройках «Горячие клавиши».

### 5.6. Командная палитра

Быстрый доступ к действиям: открыть раздел, создать заметку, запустить задачу,
переключить тему, найти команду. Работает по `Ctrl+K` и из панели задач.

## 6. Профили и данные

### 6.1. Что такое профиль

Профиль — независимое пространство:

- заметки, книги, медиа, история;
- настройки интерфейса и модулей;
- права доступа и пароль;
- собственные расширения и приложения;
- собственный кэш и индексы.

### 6.2. Где лежат данные

```
data/profiles/<профиль>/
├─ config.json          # настройки профиля
├─ data/                # заметки, книги, медиа, соцсеть
├─ stats/               # статистика
├─ extensions/          # расширения профиля
└─ backups/             # резервные копии
```

Глобальные кэши — в `~/.infinity` (модели, Hermes, расширения по умолчанию).

### 6.3. Активный профиль

Профиль выбирается при входе. Активный профиль определяет, какие данные видны,
какие настройки применяются и какие расширения загружены.

### 6.4. Пароли и доступ

Пароль профиля хранится в защищённом виде. Админ может сбросить пароль, заблокировать
профиль, клонировать данные и выдать доступ.

### 6.5. Перенос профиля

1. Закройте приложение.
2. Скопируйте папку профиля.
3. На новом компьютере положите её в `data/profiles`.
4. Запустите приложение и выберите профиль.

## 7. Поиск и индексы

### 7.1. Источники

Поиск умеет искать по:

- файлам и папкам;
- заметкам;
- книгам;
- новостям;
- HTML-страницам и сохранённым сайтам;
- ZIM-энциклопедиям;
- истории браузера;
- медиатеке.

### 7.2. Как работает индексация

1. Сканируются указанные каталоги.
2. Определяется тип файла.
3. Извлекается текст: PDF, EPUB, FB2, DOCX, HTML, TXT.
4. Строится полнотекстовый индекс.
5. Для семантического поиска считаются эмбеддинги.
6. Индекс сохраняется на диск и обновляется инкрементально.

### 7.3. Полнотекстовый поиск

Используются:

- Tantivy;
- BM25;
- собственный поисковый движок;
- Whoosh (в отдельных режимах);
- ранжирование по свежести и релевантности.

### 7.4. Семантический поиск

- эмбеддинги fastembed;
- Qdrant;
- локальная модель эмбеддингов;
- поиск по смыслу, а не по точному слову.

Без модели эмбеддингов работает обычный полнотекстовый поиск.

### 7.5. Подсказки и опечатки

- автодополнение;
- исправление опечаток;
- синонимы;
- раскладка;
- подсветка совпадений.

### 7.6. Фильтры

- тип источника;
- дата;
- профиль;
- папка;
- жанр/категория;
- избранное;
- прочитанное.

### 7.7. Сниппеты и кэш

Для документов сохраняются фрагменты и кэш чтения. Повторное открытие происходит
быстрее. Кэш можно очистить в настройках.

### 7.8. Переиндексация

Полная и частичная. Запускается вручную или по расписанию. Тяжёлая операция
выполняется в фоне и не блокирует интерфейс.

## 8. Заметки и знания

### 8.1. Редакторы

Доступны несколько режимов:

- простой текст;
- Markdown;
- таблицы;
- код;
- фокус;
- граф.

Переключение — в верхней панели редактора.

### 8.2. Форматирование

- заголовки, списки, цитаты;
- чек-листы;
- таблицы;
- формулы;
- графики Plotly;
- вложения и изображения;
- ссылки и сноски;
- теги.

### 8.3. Папки и коллекции

Заметки можно раскладывать по папкам, объединять в коллекции и вики-страницы,
экспортировать в Markdown, HTML и другие форматы.

### 8.4. Граф связей

Граф показывает:

- связи между заметками;
- темы и группы;
- самые связанные узлы;
- смысловые кластеры;
- фильтры по типу связи.

### 8.5. Семантический поиск

Заметки индексируются моделью эмбеддингов. Поиск находит близкие по смыслу записи,
даже если слова не совпадают.

### 8.6. Быстрые заметки

`Shift+Space` открывает мини-окно поверх любого приложения. Заметка сохраняется в
выбранную папку.

### 8.7. Версии и корзина

- история версий;
- восстановление;
- корзина;
- автосохранение;
- защита от потери при закрытии.

### 8.8. Память помощника

Отдельный слой долговременной памяти: факты, предпочтения, контекст. Используется
помощником и может быть просмотрен/очищен.

## 9. Книги и ZIM

### 9.1. Форматы

- FB2;
- EPUB;
- PDF;
- TXT;
- DJVU;
- другие через Calibre.

### 9.2. Библиотека

- обложки;
- авторы;
- жанры;
- серии;
- полки;
- коллекции;
- избранное;
- рекомендации;
- статистика чтения.

### 9.3. Читалка

- оглавление;
- закладки;
- цитаты;
- поиск по книге;
- настройка шрифта и ширины;
- тёмная тема;
- сохранение позиции;
- озвучивание;
- перевод;
- заметки.

### 9.4. Конвертация

Calibre используется для конвертации редких форматов и работы с метаданными.
Без Calibre доступны основные форматы.

### 9.5. ZIM

ZIM — офлайн-архивы Kiwix:

- Википедия;
- WikiHow;
- учебники;
- справочники.

Архивы кладутся в `data/zim`, после чего появляются в библиотеке. Поддерживаются
поиск, оглавление, закладки, озвучивание и экспорт.

### 9.6. Генератор книг

Сборка книги из заметок, статей и материалов. Может использовать локальную модель
для структуры и текста.

### 10.2. Видео

- встроенный плеер;

- транскод;

- альбомы;

- скачивание;

- очередь;
- выбор файлов;
- ограничение скорости;
- автосортировка.

Требует Node.js-помощник `app/torrent_helper`.

### 10.6. Настроение и рекомендации

Опциональный модуль анализирует треки и подбирает музыку по настроению. Требует
модель CLAP и включение в настройках.

## 16. Расширения

Расширения добавляют кнопки, панели, страницы, команды и хуки. Они не меняют ядро и
могут быть отключены.

Кратко:

- манифест `extension.json`;
- Python-часть `main.py`;
- JavaScript-часть `frontend.js`;
- права: `storage`, `ui:modify`, `files:*`, `network`, `api:*`, `shell`;
- хуки: книги, заметки, медиа, поиск, desktop, настройки и другие;
- sandbox для стороннего кода;
- конструктор из девяти шагов;
- маркетплейс, обновления, резервные копии и откат.

Полная документация: [`EXTENSIONS.md`](EXTENSIONS.md).

## 17. Помощник и локальные модели

### 17.1. Что умеет помощник

- отвечать на вопросы по вашим документам;
- искать по смыслу;
- делать выжимки;
- помогать с текстом, переводом и кодом;
- запускать задачи по расписанию;
- вызывать инструменты;
- работать с заметками, книгами и файлами.

### 17.2. Локальный движок

`engine/` — llama.cpp с OpenAI-совместимым API. Модели `.gguf` лежат в
`models/gguf`. Параметры: контекст, GPU-слои, кэш, семплирование, MTP.

### 17.3. Внешние провайдеры

Можно подключить OpenAI-совместимый сервис: адрес, ключ, модель. Запросы идут
через `llm_router`; ключи хранятся локально.

### 17.4. Очередь инференса

Запросы не толкаются локтями: очередь распределяет их по приоритетам и не даёт
одному тяжёлому запросу заблокировать интерфейс.

### 17.5. RAG

Документы делятся на фрагменты, индексируются и подмешиваются в контекст ответа.
Источники можно показать в ответе.

### 17.6. Hermes Agent

Hermes — модуль агента:

- планировщик задач;
- инструменты;
- память;
- голос;
- веб-интерфейс;
- API.

Интеграция живёт в `app/hermes_module/integration`, сам агент — в `hermes/` и
`app/hermes_module/backend`.

### 17.7. MCP

MCP-сервер и менеджер подключают внешние инструменты и источники данных. Точки
входа: `mcp_server.py`, `mcp_manager.py`, `mcp_stdio.py`.

## 20. Безопасность

### 20.1. Локальный доступ

По умолчанию сервер слушает `127.0.0.1`. LAN-доступ включается отдельно и требует
пароля.

### 20.2. Пароли

Пароли профилей хранятся в защищённом виде. Админ может сбросить пароль, но не
видит старый.

### 20.3. Права профилей

Профиль видит только свои данные. Общий доступ выдаётся явно.

### 20.4. Sandbox расширений

Ограничивает файлы, сеть, процессы и время выполнения. Подробности — в
[`EXTENSIONS.md`](EXTENSIONS.md).

### 20.5. Шифрование

Файлы и папки можно шифровать. Ключи локальные.

### 20.6. Avi

Локальный антивирусный модуль:

- проверка файлов;
- карантин;
- журнал;
- правила;
- белые и чёрные списки.

Требует `app/bin/avi.exe` и базу сигнатур.

### 20.7. Журналы

- `logs/server.log`;
- журналы модулей;
- журналы расширений;
- аудит доступа.

## 21. Восстановление и резервные копии

### 21.1. Recovery guard

Сторож запускается вместе с приложением, считает падения и может включить
безопасный режим.

### 21.2. Безопасный режим

`--safe-mode` отключает расширения и проблемные модули. Данные не удаляются.

### 21.3. Резервные копии

- профили;
- конфигурация;
- расширения;
- критические файлы.

Копии лежат в `data/recovery_backups` и `_backups`.

### 21.4. Откат расширений

Перед обновлением создаётся копия. Если новая версия не работает, можно откатиться.

### 21.5. Восстановление данных

В админ-панели есть восстановление профилей, слотов и критических файлов.

## 27. Ограничения

- Основная платформа — Windows 10/11 x64.
- Локальный движок — кастомная сборка llama.cpp; апстрим может не поддерживать
  часть флагов.
- Hermes требует отдельный Python 3.11–3.13 или frozen-рантайм.
- Модели, ComfyUI, Calibre, VLC и каталог приложений ставятся отдельно.
- Локальный помощник требует ресурсов; на слабой машине ответы медленные.
- Федерация, новости, погода и внешние провайдеры требуют интернета.
- Расширения с `shell`/`files:write` могут навредить системе — устанавливайте
  только проверенные.
