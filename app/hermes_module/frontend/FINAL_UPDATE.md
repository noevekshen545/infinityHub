## 🚀 Как использовать

### Первый запуск
1. Запустите `START.bat`
2. Дождитесь запуска backend (Hermes Gateway)
3. Откройте http://127.0.0.1:9120
4. Frontend автоматически подключится к backend

### Работа с инструментами
- Инструменты загружаются автоматически из backend
- Каждый инструмент показывается с соответствующей иконкой
- Можно раскрыть для просмотра входных данных и результатов
- Отображается время выполнения

### Размышления агента
- Блоки размышлений можно раскрыть/скрыть
- Показывается статус (думаю/завершено)
- Содержимое отображается в читаемом формате

### Slash-команды
- Нажмите на иконку терминала в композиторе
- Команды сгруппированы по категориям
- Показывается описание и аргументы

### Рабочая директория
- Автоматически загружается из backend
- Отображается в UI если нет активного проекта
- Используется для всех файловых операций
