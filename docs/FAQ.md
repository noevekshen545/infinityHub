# Частые вопросы

## Запуск и порт

### Приложение не запускается

1. Проверьте, что путь к папке не содержит необычных символов и пробелов в начале.
2. Посмотрите `logs/server.log` — там обычно написана причина.
3. Убедитесь, что порт `8281` свободен.
4. Запустите `start.bat` от имени обычного пользователя, без ограничений папки.

### Порт 8281 уже занят

Закройте другую копию приложения или запустите на другом порту:

```bat
start.bat --port 8282
```

Затем откройте <http://127.0.0.1:8282>.

### Windows предупреждает о неизвестном издателе

Это SmartScreen для программ без цифровой подписи. Нажмите «Подробнее» →
«Всё равно запустить». Скачивайте архив только из официального раздела Releases.

### Приложение открывается, но страница пустая

Подождите 10–20 секунд при первом запуске: создаются профили и индексы. Если не
помогло — проверьте `logs/server.log` и обновите страницу.

## Данные и резервные копии

### Где хранятся мои данные

Всё лежит в папке `data/` рядом с приложением:

```
data/profiles/<профиль>/   заметки, настройки, книги, медиа
data/index/                поисковые индексы
data/zim/                  офлайн-энциклопедии
data/html/                 сохранённые страницы
```

Модели — в `models/`, движок — в `engine/`.

### Как сделать резервную копию

1. Закройте приложение.
2. Скопируйте папку `data/` целиком.
3. Для полной копии добавьте `models/` и `app/config.json`.

### Как перенести на другой компьютер

1. Распакуйте приложение на новом компьютере.
2. Замените `data/` своей копией.
3. Проверьте пути в настройках — старые абсолютные пути могут не совпадать.
4. Модели и движок можно не копировать, а скачать заново.

### Как сбросить профиль

Создайте новый профиль в админ-панели или удалите папку нужного профиля в
`data/profiles/`. Перед удалением сделайте резервную копию.

### Забыл пароль от профиля

В админ-панели можно сбросить пароль другого профиля. Если недоступен и админ,
остановите приложение и сделайте резервную копию `data/`, затем удалите файл
профиля с паролем — данные останутся, профиль придётся настроить заново.

## Модели и помощник

### Помощник не отвечает

Проверьте по порядку:

1. Есть ли модель в `models/gguf` — файл `.gguf`.
2. Выбрана ли модель в настройках раздела «Центр моделей».
3. Запущен ли движок: `engine/llama-server.exe`.
4. Свободна ли видеопамять.

Без модели можно подключить внешний OpenAI-совместимый сервис в настройках.

### Где взять модель

Подойдёт любой gguf-файл, например Qwen, Gemma, Llama или Mistral. Положите файл в
`models/gguf` и выберите его в настройках. Подробнее — в [EXTERNAL.md](EXTERNAL.md).

### Ответы медленные

- уменьшите контекст;
- выберите модель меньше;
- включите GPU-слой, если есть видеокарта;
- закройте другие тяжёлые программы.

## Медиа, книги, браузер

### Музыка и видео не воспроизводятся

Нужен VLC или совместимый кодек. Установите VLC или положите portable-версию в
`app/vlc/portable`. Для превью и транскода также нужен ffmpeg — `bootstrap --with-ffmpeg`.

### Не открываются книги

Для EPUB, FB2 и PDF обычно достаточно встроенной читалки. Для редких форматов нужен
Calibre Portable в `calibry/Calibre`. Проверьте, что путь именно такой.

### Встроенный браузер не открывает страницы

Установите Chromium для Playwright:

```bash
./scripts/bootstrap.sh --with-playwright
```

Или в PowerShell:

```powershell
.\scripts\bootstrap.ps1 -WithPlaywright
```

### Не работают офлайн-энциклопедии

Архивы `.zim` нужно положить в `data/zim`. После этого обновите список в разделе ZIM.

## Hermes и расширения

### Раздел «Помощник» показывает диагностику

Hermes требует отдельное окружение Python 3.11–3.13. Создайте его:

```bash
./scripts/bootstrap.sh --with-hermes
```

Если Python 3.13 не установлен, поставьте его и повторите команду. Остальное
приложение продолжит работать и без Hermes.

### Расширение не устанавливается

- проверьте, что файл `.inf` или архив целый;
- посмотрите права, которые запрашивает расширение;
- отключите другие расширения и попробуйте снова;
- журнал ошибок — в `logs/`.

### После обновления пропали настройки

Настройки хранятся в `data/`. Если папка не заменялась, они должны остаться. Проверьте,
что вы обновили приложение в той же папке и не запускали второй экземпляр.

## Размер и производительность

### Почему приложение занимает так много места

Основной вес — модели, движок, медиатека и каталог приложений. Без них приложение
занимает около 4 ГБ, с моделями и ComfyUI — десятки гигабайт. Точные цифры — в
[INSTALL.md](INSTALL.md).

### Как уменьшить размер

- удалите ненужные модели из `models/`;
- отключите ComfyUI и каталог `defaultapps`, если не пользуетесь;
- очистите корзину и старые резервные копии;
- удалите кэш превью в настройках медиатеки.

### Приложение тормозит

- отключите лишние модули в настройках;
- уменьшите размер индекса и контекст модели;
- закройте вкладки браузера и лишние окна;
- проверьте свободное место на диске.

## Обновление

### Как обновиться, не потеряв данные

1. Скачайте новую версию.
2. Распакуйте в отдельную папку.
3. Перенесите `data/` и `models/` из старой папки.
4. Запустите новую версию и проверьте настройки.

### Можно ли откатиться

Да. Сохраните старую папку целиком перед обновлением. Для откатите просто запустите
её снова со своей копией `data/`.

## Безопасность

### Приложение доступно по сети?

По умолчанию доступ только с этого компьютера. Включение доступа по локальной сети
делается в админ-панели и требует пароля. Не включайте его в общественных сетях.

### Где хранятся пароли

В профилях, в зашифрованном виде. Не передавайте папку `data/` посторонним: в ней
могут быть личные заметки, история и токены внешних сервисов.

### Можно ли запускать без интернета

Да. Интернет нужен только для новостей, погоды, внешних моделей и федерации.
