# Code of conduct

This is a small, local-first project. Keep discussions technical and respectful.

- Do not harass, insult or discriminate against other people.
- Do not publish private data, credentials, logs or screenshots of other users.
- Do not use issues or pull requests for spam or unrelated promotion.
- Report security problems privately, not in public threads.
- Maintainers may edit, hide or remove content that breaks these rules.

If you see a problem, contact the maintainer through GitHub.
