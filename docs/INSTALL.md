# Установка

## Требования

| | Минимум | Рекомендуется |
|---|---|---|
| ОС | Windows 10 x64 | Windows 11 x64 |
| Процессор | 4 ядра | 8 ядер и больше |
| Оперативная память | 8 ГБ | 16–32 ГБ |
| Свободное место | 4 ГБ (без моделей) | 20–40 ГБ с моделями и каталогами |
| Python | не нужен для портативной версии | 3.12+ для запуска из исходников |
| Node.js | не нужен | 20+ для сборки Electron-окна |

Проект рассчитан на Windows. Отдельные части (сервер, поиск, заметки) технически
могут работать и на других системах, но готовая сборка и Electron-оболочка
ориентированы на Windows.

---

## Вариант 1. Портативная версия (рекомендуется)

1. Откройте раздел **Releases** на GitHub.
2. Скачайте архив `InfinitySearch-portable-*.zip` (или части архива, если он разбит).
3. Распакуйте в папку без кириллицы в пути, например `D:\InfinitySearch`.
4. Запустите `start.bat` — откроется окно приложения.
5. Если Windows покажет предупреждение SmartScreen, нажмите «Подробнее» → «Всё равно
   запустить». Это стандартное предупреждение для новых программ без цифровой подписи.

При первом запуске создаются:

```
data/      профили, индексы, заметки, кэш
logs/      журналы работы
models/    место для моделей
apps/      пользовательские приложения
```

Порт по умолчанию — `8281`. Если он занят, закройте другую копию приложения или
запустите с другим портом:

```bat
start.bat --port 8282
```

### Что уже внутри портативной версии

- Python-интерпретатор и все зависимости;
- Hermes Agent (модуль помощника);
- локальный движок llama.cpp;
- Electron-оболочка;
- ffmpeg, VLC, Playwright и Calibre — в полной сборке;
- готовые приложения и расширения — по желанию.

### Что скачивается отдельно

Модели, ComfyUI, каталог `defaultapps` и пользовательские данные не входят в архив,
потому что занимают десятки гигабайт. Подробности — в [EXTERNAL.md](EXTERNAL.md).

## Вариант 2. Из исходников

### Быстрый мастер `setup.bat`

Самый простой путь — запустить интерактивный мастер:

```bat
git clone https://github.com/noevekshen545/infinitygihub.git
cd infinitygihub
setup.bat
```

Он проверит Python, создаст `.venv`, поставит зависимости и задаст вопросы про
дополнительные компоненты:

- Electron и зависимости `desktop/`;
- ffmpeg;
- Chromium для Playwright;
- Whisper (tiny/base/small/medium/large);
- Silero TTS;
- голос Piper;
- Qdrant и модель эмбеддингов;
- Hermes Agent;
- llama.cpp и gguf-модель;
- VLC, Calibre, ComfyUI, `defaultapps`;
- торрент-помощник и ярлык на рабочем столе.

Можно выбрать только нужное и пропустить остальное.

### 1. Установите Python

Скачайте **Python 3.12 x64** с [python.org](https://www.python.org/downloads/) и
включите галочку **Add python.exe to PATH**.

Проверка:

```bat
python --version
```

### 2. Склонируйте репозиторий

```bash
git clone https://github.com/noevekshen545/infinitygihub.git
cd infinitygihub
```

Без Git можно скачать ZIP-архив репозитория и распаковать его.

### 3. Запустите bootstrap

Git Bash / WSL:

```bash
./scripts/bootstrap.sh
```

PowerShell:

```powershell
.\scripts\bootstrap.ps1
```

Скрипт создаст `.venv`, установит зависимости из `requirements.txt`, создаст рабочие
каталоги и, если найден npm, поставит зависимости Electron-оболочки.

Полезные флаги:

| Флаг (bash / PowerShell) | Что делает |
|---|---|
| `--with-playwright` / `-WithPlaywright` | скачивает Chromium для встроенного браузера |
| `--with-ffmpeg` / `-WithFfmpeg` | скачивает ffmpeg в `app/binaries/ffmpeg` |
| `--with-hermes` / `-WithHermes` | создаёт отдельное окружение Hermes (Python 3.11–3.13) |
| `--engine-url URL` / `-EngineUrl URL` | скачивает архив движка в `engine/` |
| `--engine-from DIR` / `-EngineFrom DIR` | копирует движок из локальной сборки |
| `--hermes-url URL` / `-HermesUrl URL` | скачивает Hermes из архива |
| `--hermes-from DIR` / `-HermesFrom DIR` | копирует Hermes из локальной сборки |
| `--no-desktop` / `-NoDesktop` | не устанавливать Electron-зависимости |
| `--all` / `-All` | Playwright + ffmpeg + окружение Hermes |

### 4. Запустите приложение

```bat
run-dev.bat
```

или вручную:

```bat
cd app
..\.venv\Scripts\python.exe main.py --server --port 8281
```

Откройте <http://127.0.0.1:8281>.

### 5. Electron-окно (необязательно)

```bat
cd desktop
npm install
npm start
```

Оболочка ищет `InfinitySearch.exe` рядом с собой. Для запуска из исходников можно
пользоваться веб-интерфейсом или указать в `desktop/main.js` путь к Python.

## Обновление

### Портативная версия

1. Скачайте новый архив.
2. Распакуйте в новую папку.
3. Скопируйте туда `data/` и `models/` из старой папки.
4. Запустите `start.bat`.

### Из исходников

```bash
git pull
./scripts/bootstrap.sh
```

Зависимости обновятся, пользовательские данные в `data/` останутся на месте.

---

## Удаление

1. Закройте приложение.
2. Удалите папку с программой.
3. Если нужна полная очистка, удалите также `%USERPROFILE%\.infinity` — там могут
   лежать кэш, профили Hermes и служебные файлы.

Перед удалением сделайте резервную копию `data/`, если там есть нужные заметки,
книги или настройки.

## Частые проблемы при установке

| Симптом | Решение |
|---|---|
| `Python 3.12+ not found` | Установите Python 3.12 и включите «Add to PATH» |
| `pip install` падает на `torch` | Освободите диск и повторите; можно поставить CPU-версию torch |
| Порт 8281 занят | Закройте вторую копию или запустите с `--port 8282` |
| Окно Electron не открывается | Проверьте `desktop\node_modules\electron`; выполните `npm install` в `desktop` |
| Нет звука в медиа | Установите VLC или положите portable VLC в `app/vlc/portable` |
| Не открываются книги | Установите Calibre Portable в `calibry/Calibre` |
| Помощник молчит | Добавьте модель в `models/gguf` или подключите внешний провайдер |

Больше ответов — в [FAQ.md](FAQ.md).
