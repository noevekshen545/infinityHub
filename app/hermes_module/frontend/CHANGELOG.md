## Как использовать

### Переключение темы
1. Нажмите на иконку луны/солнца в шапке чата
2. Или используйте Ctrl+Shift+T
3. Или выберите тему в настройках (Настройки → Общие → Тема оформления)

### Отображение tool calls
- Инструменты отображаются с соответствующими иконками
- Показывается статус выполнения (выполняется/готово/ошибка)
- Можно раскрыть для просмотра входных данных и результатов

### Отображение размышлений
- Блоки размышлений можно раскрыть/скрыть
- Показывается статус (думаю/завершено)
- Содержимое отображается в читаемом формате

## Технические детали

### SSE события
Фронтенд обрабатывает следующие SSE события от backend:
- `assistant.delta` - потоковый текст ответа
- `tool.progress` (tool_name='_thinking') - размышления агента
- `tool.started` - начало выполнения инструмента
- `tool.completed` / `tool.failed` - завершение инструмента
- `delegation.started` / `delegation.completed` - делегирование субагенту
- `run.completed` - завершение хода агента
- `error` - ошибка от gateway

### Настройки
Все настройки сохраняются в localStorage:
- Тема (light/dark)
- Язык интерфейса
- Параметры голоса
- Настройки агента
- Конфигурация инструментов
